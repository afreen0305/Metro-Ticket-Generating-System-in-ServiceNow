# Metro Ticket Generating System in ServiceNow

This repository contains the complete documentation, design reports, and phase-wise implementation details for the **Metro Ticket Generating System** built on the **ServiceNow** platform.

## 📌 Project Overview
The Metro Ticket Generating System is an automated, service-driven solution created using ServiceNow to manage metro ticketing, user requests, backend configurations, UI/UX customization, data migration, and security standards.
